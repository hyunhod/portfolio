# 📝Projects
## 1. 수도권 부동산 프로젝트 

🔹 **프로젝트 설명**
- 이 프로젝트는 사용자에게 지역별 아파트 실거래가 정보를 손쉽게 제공하는 웹 애플리케이션입니다. 

🔹 **주요 기능**
- **지역별 아파트 실거래가 랭킹**:사용자는 지역별로 거래된 아파트의 가격을 비교하여, 해당 지역의 시장 동향을 쉽게 파악할 수 있습니다.
- **조건 기반 아파트 검색**: 해당 조건에 맞는 아파트 정보를 신속하게 필터링하여 제공합니다. 이를 통해 사용자 맞춤형 검색 경험을 제공합니다.
- **최신 거래 정보 업데이트**: 실시간으로 업데이트되는 아파트 거래 정보를 통해 사용자는 최신 트렌드와 가격 변동을 즉시 확인할 수 있습니다.
- **의사소통**: 사용자들의 의견을 듣고 말할 수 있습니다.


🔹 **기술 스택**
- **백엔드**: Java, Spring Boot, JPA
- **데이터베이스**: Oracle
- **프론트엔드**: Thymeleaf, Bootstrap

## 2. 게시판 시스템 

🔹 **프로젝트 설명**
- 이 프로젝트는 강력한 게시판 시스템을 제공하며, 사용자 인증, 게시글 작성 및 관리, 댓글 및 대댓글 기능을 포함합니다.

🔹 **주요 기능**
- **회원 가입 및 로그인**: 대문자 및 숫자를 포함한 강력한 비밀번호 규칙 적용.
- **게시글 CRUD**: 게시글 작성, 수정, 삭제, 조회.
- **댓글 및 대댓글**: 게시글에 대한 댓글과 대댓글 기능.
- **파일 업로드**: 게시글에 파일 첨부 기능.
- **페이지네이션 및 검색**: 많은 게시글을 효율적으로 탐색할 수 있는 기능.

🔹 **기술 스택**
- **백엔드**: Java, Spring Boot, JPA
- **데이터베이스**: Oracle
- **프론트엔드**: Thymeleaf, Bootstrap
